# Copium Client

A visuals-only Fabric client for Minecraft 1.21.11, forked from
**SoberClient by Violet** with every cheat removed.

> Work in progress. The source is being rebuilt from SoberClient 1.0.0.

## What it is

- Forked from SoberClient 1.0.0 (GPL-3.0-or-later). See `upstream/SoberClient-NOTICE.md`.
- No ESP, finders, movement or combat hacks, macros, auction automation or anti-vanish.
- No auto-updater, no telemetry.
